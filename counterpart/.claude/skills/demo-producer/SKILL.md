# Counterpart Demo Producer

The 30-second comparison clip is your highest-leverage marketing artifact. Per the branding doc:

> "A 30–60 second screen recording showing Counterpart's response to the same question for two different users — one a beginner, one an expert; or one with project context, one without. The visible difference between the responses is the entire pitch in 30 seconds."

The goal: make the personal-AI claim concrete in something a person can watch in less time than reading a tweet.

## The clip formula

A great comparison clip has these elements:

1. **A specific, named user** — "Sam, A-level student preparing for SATs" beats "a student"
2. **A specific, real-sounding question** — "Can you walk me through how to find the eigenvalues of a 3x3 matrix?" beats "Help me with linear algebra"
3. **Two responses, side-by-side or sequential** — Counterpart and ChatGPT (or Counterpart with profile vs Counterpart without)
4. **A visible difference** — the difference must be obvious in 5 seconds, not subtle. Highlight the moment.
5. **A caption that names the difference** — text overlay or final card stating what just happened

## Comparison axes that work

These are the categories where the difference is most visible:

### Level calibration

Same question, two users at different levels. The Counterpart response is calibrated to the user's actual level; ChatGPT defaults to a generic middle.

Example: "Sam (A-level student) asks 'how do neural networks learn?' vs Marcus (ML researcher) asks the same."
- Counterpart for Sam: explains via gradient descent analogy, uses worked numbers
- Counterpart for Marcus: discusses curvature, second-order methods, when SGD is wrong
- ChatGPT: same generic mid-level answer to both

### Style adaptation

Same level, different style preferences. Counterpart adapts; ChatGPT doesn't.

Example: "Two students ask the same probability question. Sam prefers worked examples. Alex prefers first-principles derivations."
- Counterpart for Sam: starts with a coin-flip example, builds up
- Counterpart for Alex: derives Bayes' theorem from joint probability, then applies
- ChatGPT: same response to both

### Project memory

Same prompt, different conversation history. Counterpart remembers; ChatGPT doesn't.

Example: "User asks 'should I use Postgres or MongoDB?' One has been discussing a real-time analytics dashboard for the last three sessions; the other is starting fresh."
- Counterpart with context: "Given the analytics dashboard you've been building, Postgres + Timescale would handle your time-series queries better than Mongo. Specifically because [referencing earlier conversation]."
- Counterpart without context: generic comparison
- ChatGPT: same generic comparison regardless

### Pushback (decision-type, when complement activates)

User asking a leading question that assumes their conclusion. Counterpart surfaces what they're missing; ChatGPT validates.

Example: "User asks 'I'm definitely right that founders should pick interesting problems over lucrative ones, right?'"
- Counterpart: takes the position seriously but surfaces the cases where the heuristic fails
- ChatGPT: agrees enthusiastically

### Honest uncertainty

User asks something where the honest answer is "we don't know." Counterpart says so; ChatGPT confabulates confidently.

## Anti-patterns (don't make these clips)

- **The unfair fight.** Don't make ChatGPT look stupid by asking it something it can't possibly know. Use questions where both can plausibly answer; the difference is in how well.
- **The cherry-picked moment.** If the difference happens once in 50 attempts, the clip is dishonest. Pick categories where the difference is reliable.
- **The talking head.** Don't open with the founder explaining what you're about to see. Show, don't tell. Caption can come at the end.
- **The text wall.** A 30-second clip should not require reading two paragraphs of overlay. Highlight the differentiating sentence; let the rest blur.
- **The "ChatGPT wrong, Counterpart right."** This is rarely true and creates false expectations. The pitch isn't "more accurate" — it's "calibrated to you specifically."

## Production checklist

Before recording:
- [ ] Real user profile in Counterpart, not a fake one. Use a profile generated by actual conversations (the founder's, an alpha user with permission, or a clearly-marked synthetic case).
- [ ] Clean ChatGPT account or fresh Claude.ai conversation (no prior conversation context). Note in the clip if it's ChatGPT or Claude.
- [ ] Same exact prompt, copy-pasted to both
- [ ] Both responses streamed in real time (not pre-recorded text)
- [ ] Side-by-side layout (vertical for mobile, horizontal for desktop) or sequential with clear transition

During the clip:
- [ ] First 3 seconds: show the user profile context ("Sam, A-level student, working on linear algebra")
- [ ] Next 3 seconds: show the question
- [ ] Next 18–22 seconds: both responses streaming, with the differentiating moment highlighted
- [ ] Final 4–6 seconds: caption naming the difference and a one-line CTA ("Counterpart — counterpart.ai" or whatever the new name is)

After:
- [ ] Caption written for the platform (X has different needs than LinkedIn)
- [ ] No music, or unobtrusive ambient. Voiceover only if the founder is comfortable on audio.
- [ ] Captioned for accessibility and silent autoplay
- [ ] Aspect ratio: 9:16 for X/TikTok/Instagram, 16:9 for YouTube/Twitter desktop, square for LinkedIn

## Caption / post copy

When the clip goes on X, the post needs to do work too. Use the founder voice (see `counterpart-founder-voice`):

- Lead with the specific case, not the generic claim. "Showing Sam, an A-level student, ask the same probability question to ChatGPT and Counterpart" beats "AI that knows you!"
- Name the difference in plain English. "ChatGPT defaults to the average user. Counterpart calibrated to Sam's actual level — worked example, no jargon, references the chapter he's stuck on."
- Don't oversell. "This won't always work" or "early days" is more credible than universal claims.

## How many clips, how often

The branding doc says 5–10 clips in the first month. Realistic plan:

- Week 2 (once you have a usable product with profile generation): record 2 clips on the level-calibration axis
- Week 3: record 2 clips on the style-adaptation axis
- Week 4 (with alpha users): record 2 clips on the project-memory axis (the most visceral category)
- Week 5: 1 pushback clip and 1 honest-uncertainty clip
- Week 6: revisit, replace the weakest clip

Aim for 1 new clip per week ongoing after launch. The library compounds — old clips work for months.

## When the user asks for help with a clip

Respond in this order:

1. **Which axis?** (level, style, memory, pushback, uncertainty) — pick one, don't try to demonstrate two in one clip
2. **The specific user profile** — if real (alpha user with permission), great; if synthetic, propose a believable one based on the target audience
3. **The specific prompt** — write 2–3 candidate prompts, pick the one most likely to produce a visible difference
4. **The expected difference** — what should the viewer notice in the first 5 seconds
5. **The caption** — text overlay copy and the social post that goes with it
6. **What to do if the difference doesn't show up on first try** — fallback prompts, or a different axis

## Tools

For the actual production:
- **Screen recording:** macOS Screenshot.app (free), Loom, Screen Studio (best output quality)
- **Editing:** CapCut (free, surprisingly good), Descript (text-based editing), Final Cut / Premiere if comfortable
- **Side-by-side layout:** Screen Studio supports this natively, or use CapCut's split-screen template
- **Captioning:** auto-caption in CapCut/Descript, then manually fix proper nouns

Don't over-invest in production. A clean unedited Loom with good content beats a polished video with weak content.
